# Support

| What you have | Where it goes |
|---|---|
| A question, an idea, "does it do X?" | [Discussions](https://github.com/orgs/Kolonnade/discussions) |
| A bug, or something that doesn't match the documentation | An issue on the repository concerned |
| A vulnerability | Privately — see [SECURITY.md](SECURITY.md) |

This is an unfunded project maintained in spare time. There is no commercial support and no response-time promise, other than the one for security reports in `SECURITY.md`. Nothing is released yet, so expect the answer to some questions to be "not built".

A question that includes the version or commit, the Go version, the database version and what you already tried gets a useful answer far faster than one that doesn't.
